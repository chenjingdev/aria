# 처음 설치한 Mac에서 소리 준비하기

Aria는 각자의 Mac에서 실행합니다. 음원을 전부 받을 필요는 없습니다.
기본 악기부터 준비하면 SFZ 엔진을 빌드하지 않고도 피아노·기타·베이스·드럼으로 시작할 수 있습니다.

1. Node.js 22 이상(권장 24 LTS)에서 `npm ci` 뒤 `npm start`로 Aria를 실행합니다. Mac에서 브라우저가 열리며, 자동으로 열리지 않으면 표시된 로컬 주소를 여세요.
2. 아직 안내를 마치지 않았다면 음원 유무와 관계없이 **Aria 시작하기**가 자동으로 열립니다. **음원 준비하기**로 들어가거나 상단 **음원 관리**를 여세요.
3. **공식 페이지에서 받기**로 [GeneralUser GS](https://www.schristiancollins.com/generaluser)를 받습니다. ZIP을 받은 경우 압축을 풉니다.
4. **받은 SF2 파일 선택**을 눌러 다운로드 폴더 안의 `.sf2` 파일을 선택합니다. Aria가 기본 악기 구성과 파일을 검사하고 자기 음원 폴더에 복사합니다. 이름 변경이나 숨겨진 폴더로의 수동 이동은 필요 없습니다.
5. **피아노 소리 확인**으로 네 음을 들어봅니다. 현재 곡이나 저장 파일은 바뀌지 않습니다. 들리지 않으면 플레이어의 재생 버튼과 Mac의 출력 장치·음량을 확인합니다.

취소하면 설치하지 않습니다. 잘못된 파일은 이유를 표시하고, 이미 있는 기본 음원은 덮어쓰지 않습니다. 기존 파일이 손상되거나 필요한 악기가 부족하면 상태를 표시합니다. 이 경우 기존 파일의 수동 점검이 필요하며 이 화면에서 교체하지 않습니다.

설치 후 악기 목록은 자동 갱신됩니다. **AI 연결하고 첫 곡 만들기**로 이어가거나 상단 **시작 안내**를 여세요. **연결 요청 복사**를 눌러 이 Mac에서 사용하는 로컬 AI 대화에 붙여넣으면 에이전트가 등록과 확인을 진행합니다. 새 대화가 필요하다는 안내를 받았을 때만 새 대화에서 확인 요청을 보내세요. 화면은 실제 MCP 도구 요청을 받은 시각을 표시하며 AI를 자동 실행하지 않습니다. [README 처음 설치하기](../README.md#처음-설치하기)를 참고하세요.

## 추가 음원

- **VSCO 2 CE:** 오케스트라 악기와 주법을 더할 때.
- **Salamander Drumkit:** 실제 녹음한 어쿠스틱 드럼을 더할 때.
- **Philharmonia:** 더 다양한 오케스트라 주법과 녹음 클립이 필요할 때.

추가 팩은 SFZ 엔진이 필요합니다. Node.js·Git·CMake를 준비하고 Aria 폴더에서 `npm run engine:install:sfizz`를 실행한 뒤 **새로 확인**을 누르세요. Philharmonia의 원본 변환에는 FFmpeg도 필요할 수 있습니다.

**공식 원본으로 설치**는 공식 서버에서 이 Mac으로 직접 받은 원본을 검증하고 로컬에서 준비합니다. 이미 받은 파일이 있다면 **이미 받은 압축파일 선택**으로 ZIP·tar.gz·tar.bz2 원본을 고릅니다. 이때는 압축을 풀지 않습니다. 설치기는 고정된 버전의 해시를 확인하므로 다른 버전은 설치하지 않습니다. 다운로드·변환·검증 동안 앱을 계속 실행해 두세요. 음원 관리 창은 닫아도 됩니다.

## 다운로드와 재배포 조건 재검토

확인일: 2026-09-05. 아래는 공식 문구에 따른 Aria의 구현 판단이며, 다운로드 기능 전체가 금지된다는 뜻이 아닙니다.

| 음원 | 공식 근거 | Aria의 처리 |
|---|---|---|
| GeneralUser GS | [라이선스](https://github.com/mrbumpy409/GeneralUser-GS/blob/main/documentation/LICENSE.txt)는 음악 제작과 소프트웨어 사용·패키징을 허용하고, 제작자 웹사이트의 다운로드 파일에 대한 직접 링크를 피하라고 안내합니다. [공식 README](https://github.com/mrbumpy409/GeneralUser-GS)는 저장소를 자동 패키징 소스로 제공한다고 설명합니다. | 자동화 자체가 금지된 것으로 해석하지 않습니다. 이번에는 공식 페이지 방문 → 사용자가 받은 SF2 선택을 구현했습니다. 파일의 출처를 인증하거나 다른 SF2를 GeneralUser로 판정하지 않습니다. |
| VSCO 2 CE | [공식 저장소](https://github.com/sgossner/VSCO-2-CE)의 CC0-1.0 | 기존 공식 원본 다운로드·검증·로컬 설치 유지. |
| Salamander Drumkit | [저자 페이지](https://rytmenpinne.wordpress.com/sounds-and-such/salamander-drumkit/)는 2022-03-04 public-domain 전환을 고지합니다. 고정된 원본 README에는 CC BY-SA 3.0이 남아 있습니다. | 기존 다운로드 유지. 고정 archive의 라이선스 메타데이터를 바꿔 기존 설치 검증을 깨뜨리지 않고 두 근거를 함께 보존합니다. |
| Salamander Grand Piano | [FreePats 공식 페이지](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html)의 CC BY 3.0 | 자동 다운로드를 일괄 금지할 근거가 없습니다. 이번 기본 음원 설치 화면은 GeneralUser용이며 별도 Salamander 피아노 설치 자동화는 추가하지 않았습니다. |
| Philharmonia | [공식 조건](https://philharmonia.co.uk/resources/sound-samples/)은 상업 음악을 포함한 작품 사용을 허용하지만, 샘플이나 샘플러 악기 자체의 판매·제공은 금지합니다. | Aria에서 샘플이나 변환된 악기를 호스팅·묶음 배포하지 않습니다. 공식 원본을 사용자 Mac으로 받아 로컬에서 준비하는 기존 기능을 유지합니다. 공식 문구가 자동 다운로드를 명시적으로 승인한 것은 아니며, 이 흐름은 재배포와 구별한 구현상 판단입니다. 공식 페이지에서 직접 받은 ZIP 선택도 지원합니다. |

기본 음원 가져오기와 네 음 재생, HTTP 취소·오류·기존 파일 보존은 격리된 테스트로 검증합니다. 모든 대형 음원을 새 Mac에서 다시 다운로드한 검증과는 구별합니다.
