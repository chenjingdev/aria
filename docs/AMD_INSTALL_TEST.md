## 정리 상태와 남은 검증

amd의 테스트 앱, node_modules, 설치 음원, 공식 다운로드 원본, 전송 archive, 테스트 실행 스크립트는 제거했습니다. 테스트 Node 프로세스도 0개입니다. 원격에는 작은 결과 JSON 두 개만 `C:\Users\chenj\AppData\Local\Temp\aria-install-audit-20260905\evidence`에 남겼으며 Mac의 `output/amd-install-test/`에도 복사했습니다.

추가 SFZ 대형 팩 전체, SFZ 엔진 빌드, 외부 AI 클라이언트 등록, Mac 시스템 파일 선택창과 실제 스피커 재생은 이번 반복 설치 검증에 포함되지 않습니다. 새 Mac에서 이 항목을 포함한 최종 사용자 검증이 필요합니다.

테스트 준비 중 PATH의 Git GNU tar가 Windows 드라이브 경로를 원격 주소로 해석해 실패하여 Windows 기본 tar로 바꿨습니다. 테스트 실행기의 종료 대기 처리도 Windows의 signalCode를 반영해 수정한 뒤, 두 회차를 처음부터 다시 통과했습니다. 이 두 문제는 테스트 도구 문제이며 Aria 제품 오류로 집계하지 않습니다.
