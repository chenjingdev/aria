# v0.1.0-alpha.1 UI/UX 검토

검토일: 2026-09-05. 별도 UI/UX 에이전트가 빈 음원 및 기본 음원 준비 상태를 격리한 macOS 앱·브라우저에서 점검했습니다.

## 판단

CLI형 AI 도구를 이미 사용하는 Mac 사용자가 음원을 준비하고 AI를 등록한 뒤 작곡할 수 있는 알파 경험입니다. 다운로드만 하면 AI까지 자동으로 작동하는 일반 소비자용 설치 앱은 아닙니다. 공개 범위는 AI 작곡·듣기·기본 조절·보관·오디오 내보내기입니다.

| 발견한 막힘 | 반영한 수정 |
|---|---|
| 빈 화면에서 다음 행동이 불분명 | 상단 시작 안내와 빈 화면의 AI 연결·첫 곡 버튼 |
| 음원 설치 뒤 외부 AI로 이어지는 안내 단절 | 준비 완료에서 AI 안내로 이동, 실제 경로의 등록 명령·확인 요청·첫 곡 요청 복사 |
| 도구 연결 여부를 사용자가 알기 어려움 | 인증된 MCP 요청 시각 표시, 일반 GUI 조작은 연결 완료로 표시하지 않음 |
| 아직 불완전한 노트 편집이 기본 기능처럼 노출 | 상세 편집·A/B·메모는 명시적으로 켜는 실험 기능으로 이동, 새로고침 시 해제 |
| 메모 저장을 AI 자동 실행으로 오해 | 구간과 요청을 복사해 외부 AI에 직접 전달하는 방식 명시 |
| 새 곡 생성 시 현재 작업 보존 여부가 불분명 | 현재 곡을 보관한 뒤 새 곡을 만든다는 확인 문구 |
| 시작 로그의 수천 개 파일명이 GUI 주소를 밀어냄 | 미설치 음원 종류 수와 안내로 요약 |
| 빈곡 get_song 오류 때문에 최초 연결 확인 실패 | 곡 없음과 정상 연결·GUI 주소를 성공 응답 |

## 검증

- 실제 `/api/setup` 응답의 버전·기본 음원 상태·등록 명령 표시 및 클립보드 내용 확인.
- GUI 요청과 인증된 MCP 요청을 구분한 최근 요청 시각 확인.
- 기본 상태의 노트 더블클릭·Delete가 곡을 변경하지 않고, 실험 기능을 켠 뒤 실제 노트 추가가 동작함을 확인. 새로고침 시 다시 꺼짐.
- 음원 준비 완료에서 AI 안내로 이동, 선택 구간·요청 문구 복사 확인.
- 1440×900 및 390×844에서 가로 넘침 없음, 주요 버튼 접근 가능, 브라우저 콘솔 오류·경고 0.

브라우저 검증의 음원은 테스트용이며 외부 AI 로그인과 공식 사이트 다운로드는 대체하지 않습니다. 새 물리 Mac의 OS 권한·파일 선택·청취까지 처음 보는 사용자가 수행하는 테스트는 별도로 남아 있습니다. 세부 편집의 모든 제스처·인자 조합을 완성한 것으로 판정하지 않습니다.
