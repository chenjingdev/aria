# 첫 공개 프리뷰의 기능 범위

검토일: 2026-09-05. 이 문서는 **AI가 곡을 만들고, 사용자가 듣고 보관하고 내보내는 macOS 로컬 작곡 프리뷰**의 공개 범위를 정합니다. 모든 세부 편집을 완성한 DAW나 AI가 내장된 서비스로 소개하지 않습니다.

## 처음 설치한 사람이 할 수 있어야 하는 일

기본 경로는 저장소 받기 → 의존성 설치 → 실행 → 기본 SF2 음원 준비 → 외부 AI의 MCP 연결 → 첫 곡 만들기 → 재생 → 보관 → WAV 내보내기입니다.

- 기본 음원만으로 첫 곡을 만들 수 있어야 합니다. SFZ 엔진 빌드와 대형 오케스트라 팩은 추가 선택입니다.
- 외부 AI 도구는 사용자가 별도로 준비합니다. Aria 화면에 채팅 입력창이 생기는 구조가 아닙니다.
- 기본 SF2만 설치한 환경의 음색은 벤치마크에서 추가 팩을 사용한 곡과 다를 수 있습니다. 설치한 프리셋을 확인하고 그 범위로 작곡해야 합니다.
- WAV는 기본 내보내기 경로입니다. MP3에는 FFmpeg가 필요합니다. MIDI는 현재 소리의 모든 주법·믹스 처리를 보존하지 않으므로 오디오와 별도의 사용 목적을 갖습니다.

음원 준비와 조건은 [처음 소리 준비하기](SOUND_SETUP.md), 재생·내보내기 제한은 [README](../README.md#알려진-한계)를 따릅니다.

## 공개에서 약속하는 범위

| 범위 | 사용자에게 제공하는 동작 | 근거와 경계 |
|---|---|---|
| AI 작곡 | 악기 찾기, 곡·트랙 만들기, 노트 입력, 곡 전체 작성, 템포·구간 구성 | 벤치의 여러 실행에서 사용된 핵심 경로입니다. 모델·하네스에 따라 결과와 필요한 재시도는 달라집니다. |
| 곡 듣기 | 브라우저에서 곡 확인, macOS 재생·정지·구간 듣기 | 렌더된 오디오를 듣는 경로입니다. 루프 경계와 렌더 대기시간을 포함해 실시간 DAW 재생과 차이가 있습니다. |
| 기본 조정 | 트랙 악기·볼륨·팬·주법 변경, 템포, AI의 구간 음량·주법 수정 | 실제 벤치에서 사용되었습니다. 모든 인자 조합이나 장시간 반복 편집을 벤치가 검증한 것은 아닙니다. |
| 보관·결과물 | 자동 저장, 이름 붙여 보관, GUI에서 저장 곡 열기, WAV·조건부 MP3 내보내기 | 보관·내보내기는 벤치 사용 증거가 있습니다. GUI의 저장 곡 열기는 실제 사용을 위한 기본 기능이며 별도의 회귀 검증으로 확인합니다. 기본 MCP에서는 `save_song`을 제공하고 곡 불러오기는 GUI에서 합니다. |
| 첫 설치 | 음원이 없는 상태 안내, 공식 페이지로 이동, 받은 SF2 선택·검사, 소리 확인, AI 연결 안내 | 벤치와 별개의 설치 검증 대상입니다. 기존 개발자 Mac에 모든 팩이 있다는 사실을 신규 사용자에게 적용하지 않습니다. |

## 세부 편집은 프리뷰 기능

피아노롤 직접 조작, 개별 노트 이동·길이·분할, 피치 벤드, 복잡한 구조 재편집, MIDI 가져오기, A/B 비교, 구간 피드백을 통한 반복 협업은 코드에 존재하더라도 첫 공개의 완성도 약속에 포함하지 않습니다. 화면과 문서에서 프리뷰임을 표시하고 처음 곡을 만드는 경로와 구분합니다.

기존 데이터나 동작을 제거할 필요는 없습니다. 안전한 복구를 위한 되돌리기·다시하기와 곡 보관은 유지합니다. 다만 **도구가 노출되어 있었음**, **벤치에서 실제 호출되었음**, **편집 정확성을 별도 테스트했음**, **사람이 쓰기 편함**은 서로 다른 근거입니다. 하나가 다른 셋을 대신하지 않습니다.

## 기본 MCP 프로필

첫 공개 브리지의 기본 프로필은 `release`로 정하고 벤치가 노출한 37개 도구를 제공합니다. 피드백·A/B·저장 곡 탐색과 불러오기·MIDI 가져오기 8개 MCP 도구는 기본 목록에서 제외합니다. GUI의 곡 보관·불러오기와 내부 구현은 유지합니다.

전체 45개 MCP 도구는 `ARIA_TOOL_PROFILE=full`을 명시한 개발·실험 환경에서 사용합니다. `ARIA_HIDE_TOOLS`는 선택한 프로필에서 추가로 숨기는 이름 목록이며, 프로필의 숨김을 취소하지 않습니다. 숨긴 도구는 MCP 안내문에서도 제외합니다. 처음 사용하는 사람을 위한 안내에는 `full`을 요구하지 않습니다.

이 선택은 벤치 당시 AI에 제공했던 작업 범위를 재현합니다. 37개 전부가 실제 사용성 검증을 끝냈다는 의미는 아닙니다.

## 벤치마크가 실제로 보여 준 범위

2026-09-05 벤치 공개 산출물의 두 과제·20개 실행 과정을 집계했습니다. 원본 곡이나 대화 전문 대신 도구 이름·호출 횟수·오류 표식만 검토했습니다.

- 벤치 앱 프로필은 Aria 도구 **37종**을 허용합니다. 검토 시점 MCP 전체는 **45종**입니다.
- 숨긴 8종: `list_feedback`, `resolve_feedback`, `add_feedback`, `ab_save`, `ab_load`, `list_songs`, `load_song`, `import_midi`.
- 공개 과정 로그에는 Aria MCP 호출 **1,729회**, 하네스 자체 도구 호출 **307회**가 기록돼 있습니다. 실제 호출된 Aria 도구는 **23종**입니다.
- 벤치 러너의 기본은 앱 작곡 스킬을 설치하지 않는 raw 프로필입니다. 앱 설정의 `skills` 배열은 설치할 수 있는 스킬 위치이며, 그것만으로 해당 실행에 스킬을 설치했다고 판단하지 않습니다.
- 일부 실행은 하네스 스크립트의 직접 HTTP 요청을 사용했습니다. GPT-OSS 자유곡은 추가 확장 지시 1회와 벤치 측 MP3 렌더가 산출물 조건에 명시돼 있습니다. 따라서 20개 결과를 모두 “MCP만으로 사람 개입 없이 한 번에 성공”한 증거로 소개하지 않습니다.

### 노출되었지만 호출 증거가 없는 도구

`remove_track`, `swing`, `quantize`, `remove_section`, `delete_note`, `move_note`, `resize_note`, `split_note`, `set_bend`, `delete_bars`, `move_notes`, `undo_edit`, `redo_edit`, `edit_history`.

이 14종은 해당 벤치로 사용성을 판정할 수 없습니다. 되돌리기처럼 첫 공개에 필요한 기능은 벤치 호출 수와 별개로 검증하고 유지합니다.

### 증거 위치

현재 저장소의 도구 정의는 [`src/mcp.js`](../src/mcp.js), 숨김 동작은 [`src/mcp-bridge.js`](../src/mcp-bridge.js)와 [`test/mcp-hide.js`](../test/mcp-hide.js)에 있습니다.

집계 입력은 이 저장소에 포함하지 않은 로컬 벤치 프로젝트 `aria-bench-site-2026-09-05`의 `public/data/process/*.calls.jsonl` 20개, `public/data/process/summary.md`, `lib/data/runs.json`의 `conditions`입니다. 노출 목록은 벤치 앱 프로필의 `tools.aria`와 `mcp.aria.env.ARIA_HIDE_TOOLS`, raw 기본값은 bench 플러그인 README로 확인했습니다. 이 문서의 집계는 그 시점의 스냅샷이며 향후 실행 결과를 자동 반영하지 않습니다.

## 릴리스 검증 결과

전체 18개 자동 테스트 스크립트가 통과했습니다. 새 설치 통합 검사 24개는 별도 앱 프로세스와 실제 MCP 연결로 빈 상태 확인, 기본 음원 설치, 곡 작성·저장·비무음 WAV 생성, 앱 재시작 후 복원을 확인합니다. 이 검사에서 파일 선택창 결과는 테스트 음원으로 대체합니다. 기본 37종/full 45종, 추가 숨김 합집합, 잘못된 프로필 종료도 실제 도구 목록과 호출로 검증합니다.

음원 선택 취소·손상·중복 가져오기·기존 파일 보존, MP3 인코더 부재 오류, 저장 폴더 취소, MCP 연결 회귀도 통과했습니다. UI/UX 에이전트는 초기·설치 완료 화면, 명령/요청 복사, 실제 도구 시각, 실험 기능 off/on, 좁은 창의 접근성을 점검했습니다. [UI/UX 검토](UX_REVIEW.md)와 [릴리스 노트](../CHANGELOG.md)를 참고하세요.

새 물리 Mac에서 처음 보는 사람이 공식 사이트 다운로드·OS 선택창·외부 AI 로그인·스피커 청취까지 완료하는 사용성 테스트는 남아 있습니다. 대형 SFZ 팩 전체를 새로 받는 테스트도 이 릴리스의 설치 검사에 포함하지 않았습니다. AMD의 Windows 검증은 이 Mac 사용자 경험을 대체하지 않습니다.

## 버전 받기

태그만 생성하면 기존 사용자의 `git pull` 대상은 바뀌지 않습니다. 공개할 커밋을 기본 브랜치 `main`에도 반영하고 같은 커밋에 현재 프리뷰 태그를 붙입니다. 최초 공개는 `v0.1.0-alpha.1`, 연결 요청과 안내 완료 흐름을 개선한 버전은 `v0.1.0-alpha.2`입니다. 이후 미완성 개발은 공개 버전과 분리해 진행하고, 정확히 고정된 버전이 필요한 사람은 태그를 선택합니다. 코드·MCP·화면은 package.json의 같은 버전을 사용합니다.
